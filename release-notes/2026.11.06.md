# 更新说明 v2026.11.06（版本 31）

## 勿扰模式加固：App 被杀后也能自动关闭勿扰

**问题**：真我/ColorOS 等国产 ROM 在应用被后台清理（最近任务划掉）后，系统启动管理器会拦截所有第三方拉起路径（闹钟拉起 Activity/服务/广播全部被拦），导致勿扰模式无法在结束时间自动关闭。

**本次改动**：

1. **白名单引导强化**
   - 每次设置勿扰/午睡勿扰都会重新检查（1 小时内不重复弹），不再"只弹一次就永远消失"
   - 对话框新增「打开自启动设置」直达按钮
   - 明确说明不设置白名单的后果：被杀后勿扰无法自动关闭

2. **勿扰关闭闹钟注册进系统时钟**
   - 关闭闹钟带 showAlarmIntent，出现在系统时钟应用的闹钟列表中
   - 变成用户可见的「真闹钟」，到点由时钟应用拉起，存活率更高

3. **关闭失败可见**
   - 关闭失败（无勿扰权限/异常）时发常驻高优先级通知「勿扰模式未自动关闭」，点进应用可手动处理
   - 不再无声失败

**版本号**：31 / 2026.11.06

## ⚠️ 重要：请手动加白名单

代码无法绕过系统启动管理器的拦截，请务必手动完成（一次性）：

1. **自启动**（最关键）：设置 → 应用 → 自启动 → 找到本应用 → 打开
2. **后台不限制**：设置 → 电池 → 找到本应用 → 选择「不限制」
3. **关联启动**：设置 → 权限与隐私 → 关联启动管理 → 允许本应用
4. **锁定最近任务**：最近任务界面长按本应用卡片 → 「🔒 锁定」
